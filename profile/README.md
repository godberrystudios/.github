**Sharp scrapers and small tools for the AI agent era.**

We build focused, pay-per-use tools that do one thing fast — extract, transform, publish — without the bloat of legacy SaaS. No seats. No meetings.

---

## 🛠️ What we ship

Pay-per-use on the [Apify Store](https://apify.com/godberry?fpr=ewv9tm):

- **[Google Reviews Scraper](https://apify.com/godberry/google-reviews-scraper?fpr=ewv9tm)** — Google Maps reviews for any business in under 60 seconds. Flat fee per place ($0.10 small / $0.25 large), no API key, validated across 9 countries. Up to 68× cheaper than Google's Places API at chain scale. For reputation monitoring, lead gen, and sentiment pipelines.
- **[Google Maps Leads Scraper](https://apify.com/godberry/google-maps-leads-scraper?fpr=ewv9tm)** — turn a Google Maps search into a clean list of local business leads: name, category, rating, reviews, address, opening hours, coordinates, Maps URL. No API key. Flat **$1.50 / 1,000 results**. *(Contact enrichment — phone, website, emails incl. EU Impressum + socials — launching soon.)* For lead generation and local market research.
- **[Yelp Scraper](https://apify.com/godberry/yelp-scraper?fpr=ewv9tm)** — full Yelp business profile + all reviews + menu + photo gallery in a single call. Worldwide (any `yelp.<tld>`), multilingual dates, no Yelp Fusion API key, no 3-review cap. Pay-per-event: `$0.001` run + `$0.004`/business + `$0.0008`/review + `$0.0005`/menu item. For lead gen, competitor research, and travel/restaurant data.
- **[Google Play Reviews Scraper](https://apify.com/godberry/google-play-reviews-scraper?fpr=ewv9tm)** — Google Play Store reviews + app metadata at scale: full review text, star rating, date, app version, thumbs-up count, developer reply. No API key, no Google account, worldwide per country + language. For app intelligence and review monitoring.
